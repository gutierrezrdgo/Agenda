# Agenda

Página de agenda de Rodrigo Gutiérrez-Vásquez.

Interfaz editorial inspirada en el sistema visual de Elsewhere. La página permite seleccionar tipo de encuentro, modalidad, fecha y hora preferentes, y genera una solicitud de confirmación por WhatsApp.

## Desarrollo

```bash
npm install
npm run dev
```

## Producción

```bash
npm run build
```
